# CASH-FLOW-MINIMIZER
CASH FLOW MINIMIZER :Our project enables the user to get minimize multiple transactions,track monthly expenditure records,and borrow along with monthly emi notification .
This project helps the user to manage their finance efficiently in order to  get rid of unecessory financial missmanagement .
Our project is mainly divided into three respective modules:-

1)CASH FLOW MINIMIZER:As when many people owes money to each other ,there are too many transactions,it becomes inefficient to manage.
we want optimal algorithm with faster processing with less memory occupied ,Repeated transactions cause data Redundancy for solving these aspects in order to minimize processing time and reduce memory usage.
We use the concept of Data  structures and algorithm such as Greedy Algorithm for identification of maximum and minimum creditor or debtor respectively.Graph Theory used for identifying  (Who owes whome) ,
using heap for getting max/min immediately with time complexity O(log n),hashmaps to store and access the balance of the user.
